# GBSBFORYOU Digital Library — Business Edition v1.0

Mobile-first digital library foundation for GBSBFORYOU Publications.

## Included
- Home / featured books
- Search and category filtering
- Book detail route
- PWA manifest + service worker
- SEO starter files
- Adsterra-ready advertisement slots
- JSON-based catalog for the initial static phase

## Roadmap
1. Authors, categories and reader pages
2. Supabase Auth + PostgreSQL catalog
3. Admin publishing dashboard
4. Membership and paid-book access
5. Adsterra production code and placement controls
6. Analytics, SEO schema and production deployment

Publisher: GBSB For You, Bhopal, Madhya Pradesh
